# Toán Tiểu Học 1–5

Ứng dụng web luyện Toán lớp 1–5, giao diện cỡ điện thoại. Nội dung bám theo SGK Toán bộ **Kết nối tri thức với cuộc sống**, bộ sách dùng thống nhất toàn quốc từ năm học 2026–2027 (Quyết định 3588/QĐ-BGDĐT ngày 26/12/2025), theo chương trình GDPT 2018.

- Lộ trình theo từng chủ đề SGK, có phần Ghi nhớ và ví dụ
- Câu hỏi tạo ngẫu nhiên, có lời giải từng bước
- Toán có lời văn dạng điền bài giải (điền số, chọn phép tính, ghi đáp số và đơn vị)
- Đặt tính rồi tính cộng, trừ, nhân, chia trên bảng nháp ô li, có bàn phím số riêng
- Nuôi bạn cú, đổi bạn đồng hành, vòng quay, sticker
- Đấu trường: đề luyện thi 30 phút, thử thách 60 giây
- Trang phụ huynh: thống kê, cài đặt kỳ thi

Toàn bộ ứng dụng nằm trong một file `index.html`, không cần cài đặt hay build. Tiến độ học lưu trong trình duyệt (localStorage).
